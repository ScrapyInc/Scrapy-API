## Process

- Decisions are recorded as numbered Markdown files: `NNNN-short-title.md`.
- Statuses: `Proposed` → `Accepted` | `Rejected` | `Superseded`.
- Once an ADR is `Accepted`, it is immutable. A new decision supersedes it.
- All ADRs are reviewed at the end of each major stage.
